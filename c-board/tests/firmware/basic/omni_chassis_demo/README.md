# 十字全向轮底盘遥控控制演示

## 项目简介

本项目整合了`remote_control_demo`和`motor_test`两个测试项目的功能，实现了十字全向轮底盘的遥控控制。通过遥控器左摇杆控制底盘前进/后退和旋转，右摇杆控制底盘左/右平移，同时支持按键控制。

## 硬件配置

### 电机布局（俯视图）
```
       2
       |
   1---+---3
       |
       4
```

- 1: 右前轮 (CAN ID: 1)
- 2: 左前轮 (CAN ID: 2)
- 3: 右后轮 (CAN ID: 3)
- 4: 左后轮 (CAN ID: 4)

### 遥控器映射

- **左摇杆**:
  - 上下: 前进/后退 (vy)
  - 左右: 左平移/右平移 (vx)
  
- **右摇杆**:
  - 左右: 旋转 (wz) - 左推左转，右推右转
  - 上推: 冲刺 (提高平动速度)
  - 下推: 刹车 (降低平动速度)
  
- **按键**:
  - W: 前进 (最大速度)
  - S: 后退 (最大速度)
  - A: 向左平移 (最大速度)
  - D: 向右平移 (最大速度)
  - Q: 逆时针旋转 (最大角速度)
  - E: 顺时针旋转 (最大角速度)

## 运动学模型

采用十字全向轮运动学模型：

```
v1 = vy - vx - (L * wz)      // 右前轮
v2 = vy + vx - (L * wz)      // 左前轮
v3 = -vy + vx - (L * wz)     // 右后轮
v4 = -vy - vx - (L * wz)     // 左后轮
```

其中:
- vx: 左右平移速度 (左为正，右为负)
- vy: 前进后退速度 (前为正，后为负)
- wz: 旋转角速度 (顺时针为正，逆时针为负)
- L: 底盘中心到轮子的距离 (轮距的一半)
- v1-v4: 四个轮子的线速度

## 参数配置

- 轮子半径: 0.075 m
- 轮距: 0.34 m (轴距 25cm, 轮距 34cm)
- 最大线速度: 16.68 m/s (平动翻倍)
- 冲刺速度: 25.0 m/s (1.5倍最大速度)
- 刹车因子: 0.2 (最低速度为最大速度的20%)
- 最大旋转速度: 39.27 rad/s (旋转翻三倍)
- 控制更新频率: 50 Hz
- 电机最大速度: 30000 deg/s (~83.3 rps)

## 功能特性

1. **遥控数据接收**: 通过USART3接收DT7/DR16遥控器数据
2. **运动学解算**: 将底盘速度命令转换为四个轮子的速度
3. **电机控制**: 通过CAN1控制四个M3508电机
4. **安全保护**: 速度限制和死区处理，防止意外移动
5. **调试输出**: 通过USART6输出底盘状态和电机速度

## 注意事项

1. 确保电机ID和CAN接线与代码中定义一致
2. 首次运行时，请检查电机旋转方向是否正确
3. 遥控器未连接时，底盘不会移动
4. 如出现电机异常，请立即断电检查
