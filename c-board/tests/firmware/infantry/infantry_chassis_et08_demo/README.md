# infantry_chassis_et08_demo

纯底盘 ET08 最小测试。

目标：
- 排除云台、IMU、跟随逻辑影响
- 仅验证左摇杆平移、右摇杆 X 自转、四轮逆解和电机映射

固定物理布局：
```text
2 3
1 4
```

按云台零位定义前向时，映射解释为：
- 前左 `FL = 2`
- 前右 `FR = 3`
- 后左 `BL = 1`
- 后右 `BR = 4`

控制定义：
- 左摇杆 X：横移，左为正
- 左摇杆 Y：前后，前为正
- 右摇杆 X：底盘自转
- 右摇杆 Y：未使用

当前版本不包含：
- 云台控制
- IMU 闭环
- 底盘跟随云台
- 坐标系变换
