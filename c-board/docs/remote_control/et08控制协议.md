# ET08 遥控控制协议

文档更新日期：2026-07-23

本文档基于 ET08 + RF206S 的实测结果整理，用于后续固件解析和控制逻辑设计。
正式机器人的层次结构、安全门策略与执行层限位以
[遥控适配器与机器人输入基线](../architecture/remote_control_adapter_baseline.md)为准。

## 通道/键位映射

当前驱动解析 SBUS 的 16 个模拟通道。前 8 路有明确物理控件映射，CH9~CH16
作为统一状态中的辅助轴保留。

### 数值范围

- 驱动同时保存 `raw`（SBUS 0~2047）和 `centered = raw - 1024`。
- 摇杆与旋钮中心 raw 值为 1024；应用归一化按 ±660 处理，首轮实板必须重新校准端点。
- 组合拨杆的 RF206S 实测 SBUS 原始值为
  `1896, 1694, 1493, 554, 353, 151`。旧实现曾把后三档误写成负数并再次加中值，
  会把实际的全下位置 `151` 错判为无效。

设备层保留 SBUS 的原始中心化方向，不擅自赋予机器人动作语义。本车在 2026-07-20
实测左摇杆前推时 CH3 为负，因此机器人 ET08 Profile 对 Y 轴取反，再发布“前进为正”的
`chassis_y_intent`。左右方向已经实测正确，仍由 Profile 将左摇杆 X 映射为“向左为正”。

### 通道分配表

| 通道 | 名称 | 方向 | 说明 |
| --- | --- | --- | --- |
| CH1 | J1 | 右摇杆左右 | 右摇杆 X |
| CH2 | J2 | 右摇杆上下 | 右摇杆 Y |
| CH3 | J3 | 左摇杆上下 | 左摇杆 Y |
| CH4 | J4 | 左摇杆左右 | 左摇杆 X |
| CH5 | SA + SB | 2 级拨杆 + 3 级拨杆 | 6 档组合: 1896, 1694, 1493, 554, 353, 151 |
| CH6 | SD + SC | 2 级拨杆 + 3 级拨杆 | 6 档组合,数值同上 |
| CH7 | LD | 左旋钮 | 连续值 |
| CH8 | RD | 右旋钮 | 连续值 |
| CH9~CH16 | AUX0~AUX7 | 辅助通道 | 统一发布，当前机器人 Profile 不赋予机器人语义 |

## 组合开关解码

每个组合通道的六个状态索引为 `0~5`：

- SA/SD 为二挡上层开关：状态 `0~2=上`，`3~5=下`；
- SB/SC 为三挡下层开关：两组都按 `上、中、下` 排列，即 `0/3=上`、`1/4=中`、`2/5=下`；
- 超出 `0~5` 的状态无效，整份机器人输入按安全值处理。

该六态解码是设备层物理布局，不包含机器人模式；纯逻辑测试覆盖全部六种组合。

## 当前机器人控制逻辑

| 控件 | 当前语义 |
| --- | --- |
| 左摇杆 X/Y | 云台坐标系横移/前进意图；当前 CH3 前推负值在 Profile 中取反 |
| 右摇杆 X/Y | Yaw/Pitch 速度意图 |
| SA 下/上 | 全局安全门关闭/直接打开电平安全门 |
| SB 下/中/上 | 跟随/视觉自瞄/小陀螺 |
| SC 下/中/上 | 禁射/单发/连发 |
| SD 下/上 | 扳机释放/触发 |

四根摇杆在 Profile 中只形成 `[-1,1]` 无量纲意图。`ET08_STICK_DEADZONE_RAW` 和
`ET08_STICK_FULL_SCALE_RAW` 是 ET08 设备校准参数，不是机器人速度限制；底盘 m/s、旋转 rad/s、
云台 deg/s 和 Pitch 机械范围全部由执行层配置。

当前调试配置不要求四个开关全下、四轴回中或新的 SA 上拨边沿。遥控有效、初始化、
INS 和关键任务正常时，SA 上位直接允许控制，SA 下位立即全局停机。遥控掉线后若 SA
仍在上位，链路恢复会按电平门恢复输出；上机调试必须保证操作手可随时下拨 SA。
通用安全服务保留严格重使能能力，后续比赛阶段可通过配置重新启用。

## 驱动落点与在线判定

- 协议驱动：`components/devices/remote/et08/et08_remote.c/.h`；
- 通用后端：`components/devices/remote/et08/et08_backend.hpp`；
- 机器人映射：`applications/robot/command/et08_input_profile.cpp`；
- 正式在线截止：100 ms；帧长、帧头错误不刷新截止；单个 `frame_lost` 帧会被丢弃并保持上一份有效快照，连续 100 ms 没有有效帧才掉线；`failsafe` 仍立即让输入失效；
- 串口重初始化失败会让 `Input_Init()` 失败，正式固件保持全局输出门关闭。
