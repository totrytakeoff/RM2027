# Hero 射击机构遥控测试

## 项目简介

本项目实现英雄射击机构与云台的遥控测试：左拨杆控制摩擦轮开关，右拨杆选择发射模式，拨轮控制拨弹，右摇杆控制云台。

## 硬件配置

- 摩擦轮电机：ID 1 / 2，CAN2
- 拨弹电机：ID 5，CAN1
- yaw 轴 GM6020：CAN1 ID 2
- pitch 轴 GM6020：CAN2 ID 5

## 遥控器映射

- 左拨杆上：开启摩擦轮
- 右拨杆：
  - 下：单发
  - 中：双连发
  - 上：连发
- 拨轮向下拨：允许拨弹发射，松开停止拨弹
- 右摇杆左右：yaw 轴
- 右摇杆上下：pitch 轴（幅度减半）

## 发射逻辑

- 拨弹盘每转 60 度拨出一发
- 单发/双连发的发射间隔为 2 秒
- 连发模式使用速度模式持续拨弹
- 单发/双发使用位置模式，每 2 秒发射一组

## 构建和烧录

### 构建
```bash
cmake -S . -B build -G "Ninja" -DCMAKE_BUILD_TYPE=Debug
ninja -C build hero_shoot_test
```

### 烧录
```bash
ninja -C build upload-hero_shoot_test
```

## 注意事项

1. 确保电机 ID 与 CAN 接线一致
2. 摩擦轮未开启时拨弹将被禁止
3. 方向如不符可调整拨弹步进符号
